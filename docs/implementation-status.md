# 实施状态

本文记录可公开的功能范围与验证边界。运行实例的账号、项目、会话、恢复记录和部署地址不属于发布文档。

## 已实现的主要功能

- Gateway 登录、Host / Origin / CSRF 校验、登录限流及每用户 Agent 隔离。
- 局域网首次部署，按需启用独立 Tailscale 入口，生成 Nginx + Certbot 云端 HTTPS 中转步骤。
- 账号管理和独立授权，支持 Codex、Kimi Code 与 Claude；实际模型和权益以提供方返回为准。
- 文件浏览、预览与传输，终端、流式对话、结构化问题与工具记录、任务和历史恢复。
- Codex 原生历史共享、分支及文件回滚；共享要求同机、同一 Linux 用户及相同 CODEX_HOME。
- 同机多用户服务、共享项目权限、协作锁、数据库备份及源码发行包。

## 验证方式

```bash
npm run build
npm test
npm run test:e2e
```

浏览器测试使用独立测试数据。真实提供方探测见 [协议兼容性](protocol-compatibility.md)；探测需要操作者自己的账号与授权，不能用模拟测试代替真实登录、权益或外网验收。

0.2.0 远程管理的验证记录见 [发布说明](releases/0.2.0.md)。本地网络测试不能证明其他部署环境的公网连通性、证书签发、SSH 路径或 Tailscale 访问策略正确。

## 部署与使用边界

- 需要项目支持的 Linux、Node.js 和提供方 CLI 版本；见 README 与协议兼容性文档。
- 局域网 HTTP 仅用于可信网络；公网入口使用 HTTPS，业务保留账号密码认证。
- 持久任务由 Agent 管理，浏览器断线不代表任务取消；更新 Agent 前应确认任务状态。
- 文件权限和运行命令仍受实际 Linux 用户约束。共享项目锁只协调遵守该协议的 Relay 进程，不约束外部编辑器。
- 原生会话无法同时由多个写入者使用；接管前应阅读预览并确认影响范围。
- 实际云端部署、跨机器 SSH、物理断网和断电恢复，需要在目标环境另行验收。

详细部署步骤见 [部署文档](deployment.md)，系统设计见 [架构说明](architecture.md)。
