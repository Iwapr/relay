# Gemini（测试）

Relay 通过官方 Antigravity CLI 接入 Gemini，使用 Google 账号及其 Antigravity 订阅权益。Google AI Pro 可使用；具体模型、额度和地区资格由 Google 决定。所有入口继续标注“测试”，不会回退到 Gemini API Key。

## 安装和登录

在运行 Relay Agent 的 Linux x64 主机上，以运行服务的 Linux 用户从 Relay 目录执行：

```sh
npm run install:gemini
```

安装器下载官方 Antigravity CLI 1.2.13，校验 SHA-512 后放到 `~/.local/bin/agy`，不依赖会被发布过程排除的源码 `.runtime` 目录，也不修改 shell 配置。其他位置可通过 Agent 的 `antigravityExecutable` 指定绝对路径。登录桥接需要 Python 3。

更新并重启 Relay 后，在“账号管理 → 添加 AI 账号”选择 **Gemini（测试）**。点击“登录 Google 账号（测试）”，打开官方授权页，使用有订阅权益的 Google 账号登录，把网页显示的授权码粘贴回 Relay。Relay 把授权码交给官方 CLI，不写入 Relay 数据库或日志；确认 CLI 登录完成后才结束授权流程。

可添加 8 个 Google 账号。每个账号使用独立 HOME / XDG 目录，不连接桌面的共享钥匙串，官方 CLI 在各自目录内存储和续期凭据。不要把旧 Gemini CLI 账号目录移入此账号。切换账号不会改变已提交任务的执行账号。

## 已支持

- 文本任务、流式消息、工具结果、取消、会话恢复。取消会等待进程组终止后再完成任务；CLI 启动超过一分钟无初始化响应时报告异常，不自动重发。长任务初始化成功后不设置任意的执行时长上限。
- **消息排队和文字补充回答**：任务执行时继续发送文字，会作为下一轮排队，当前轮结束后接续；不是实时干预当前任务。
- **模型与推理强度**：模型列表来自 `agy models`。强度选项只显示该模型家族实际存在的档位，发送时切换到相应模型 slug，避免 High 模型与 Low 参数冲突。任务记录显示实际执行档位。
- **额度面板**：从官方 `agy -p /usage` 读取 Gemini 五小时／每周额度与刷新时间。不会用其他模型组的额度阻止 Gemini。额度缓存一分钟；查询失败时可显示最近结果并标记过期。邮箱和套餐名称仍显示“暂无数据”。额外 AI Credits 行为由官方 CLI 和账号设置管理，Relay 不自动购买额度。
- **命令权限界面**：在账号管理中按行编辑允许、禁止的命令前缀，例如 `python -m pytest`。禁止优先；已有文件、网络、MCP 和高级命令规则保留。保存时校验配置版本，拒绝覆盖期间发生的变更。账号有任务、恢复操作或登录流程时不能保存。无需重启，从下次任务生效。
- **原生会话发现和接续**：只读当前账号的官方 SQLite 会话索引，校验项目路径，排除子代理及多根项目记录；原生会话可在 Relay 中继续。旧消息是内部编码格式，暂不完整展示。Relay 创建过的会话与索引记录去重，仍可显示 Relay 保存的消息。正在其他进程执行的原生会话会拒绝接续。CLI 索引格式变化时明确报错，不修改原生数据库。
- **仅恢复文件**：为新任务保存执行前后恢复点，只允许恢复项目最近一轮。预览列出将修改的文件，确认前检查任务结束后的手工改动，计划过期则拒绝恢复。恢复后打开没有历史上下文的新会话，保留原对话；原模型记忆不会回退。旧任务不能补建恢复点。不恢复 Git 提交、项目外文件或外部服务。
- **错误分类**：区分授权失效、额度不足／限流、模型／强度不可用、网络、超时、沙箱和权限拒绝；不直接返回可能包含凭据的原始诊断。受限工具会显示未完成状态；异常断开标记结果待核实，不自动重试。

## 权限模式

“规划”映射官方 `--mode plan`，不是操作系统只读保证。“按规则执行”允许项目内编辑，默认允许 `ls`、`pwd`、`git status` / `diff` / `log`、`npm test`、`npm run build` / `lint` / `test`，并启用官方终端沙箱；网络和其他操作可能仍受限。需要审批的操作在后台模式下会被拒绝。

“完全访问”显式使用官方自动批准选项，不能保证取消其他本地配置或系统限制。普通模式遇到权限拒绝时，优先在账号管理中配置所需命令。

账号权限文件位于 `<Agent stateDir>/accounts/<账号 UUID>/antigravity/.gemini/antigravity-cli/settings.json`。命令规则匹配前缀及后续参数，因此允许一个解释器或脚本执行命令意味着允许相应程序执行操作。

## 仍受限制

- 图片原生输入：后台流式协议只接受文本。
- 原生逐次审批、选项式提问控件、执行中实时插入指令：没有可用的后台控制协议。文字回答与排队只能替代部分体验。
- 邮箱、Google 套餐名称：已验证的后台状态命令没有提供稳定字段，不从凭据猜测身份或权益。
- 完整原生消息导入、按历史节点分叉、对话与文件同步回滚：后台命令集合没有相应的可靠导出／分叉接口。当前只读索引接续和文件恢复不等同于这些能力。

## 验证范围

真实账号已验证官方 Google 登录、文本回复、简单命令执行、额度读取、模型列表与会话索引读取。新增目录不会继承已登录账号，官方凭据文件位于独立目录；双账号分别登录、重启保留与删除隔离通过模拟 CLI 的集成测试，第二个真实 Google 账号仍需实际授权验证。令牌长期续期和长时间复杂任务需要持续观察。

自动化覆盖权限规则冲突、多个账号、强度映射、原生索引、排队、取消、文件恢复及手工改动保护；浏览器覆盖桌面／手机端的权限保存、额度、强度、恢复文件和账号切换。模拟测试不替代真实账号长期稳定性验证。
