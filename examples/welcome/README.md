# 欢迎使用 Relay

这是一个独立的本地练习目录。可以在工作台中打开它，确认信任后使用你自己的 Codex 登录完成任务。

## 试一试

向 Codex 发送：

> 在当前目录新建 notes.md，写一份今天的研究提纲。只修改当前目录。

文件生成后，在文件列表中打开 `notes.md`。选中文档中的文字，点击预览区的引用按钮，继续提出修改要求。

## 数学公式

行内公式 $E = mc^2$ 和块级公式都可以直接预览：

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

## 关于任务

关闭网页不会取消已由常驻 Agent 接受的任务。取消按钮只请求停止后续执行，不回滚已写文件。只读模式也可能由 Codex 提出额外权限申请；请根据具体命令或文件变更决定是否批准。

此目录不包含演示会话、模拟余额或预先生成的 AI 回复。
